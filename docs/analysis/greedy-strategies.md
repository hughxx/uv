# 可证明优势与待验证策略

更新：2026-09-14。依据为当前规则材料；涉及未知判题器语义的地方显式列出条件。

## 1. “百分百优势”的标准

以下 G 条目证明的是明确前提下的动作节省、资源增量、局部支配或一次决策最优。严格收益指某指标必然更好，弱支配指不差且部分情形更好。两者都不等于不依赖局面就能保证赢比赛。

记录一个新策略时必须包含：比较对象、前提、收益／证明、反例、验证状态。若受机器人 AI、对手行为或未验证协议影响，降为 H 假说，不混入确定策略。2026-09-14 刷新后，完整任务计分 `S+5*T/t` 已明确；取整和完成记账边界仍见Q02。

这些局部性质可作为[机会驱动战术方案](opportunity-playbooks.md)的组成部分。发现破绽后的多轮执行、对手反制和优势转化由Playbook表达；若把多个G条目串起来，仍需检查阶段间条件和资源，不能自动继承为全局必胜结论。

用户所说的“事件驱动式贪心”以可修订的标准解法／兼容方案组合为选择单位：每轮根据新证据比较续打、变招、换打法的后续净增益，执行当前一步，再用实际结果纠正判断。它不是只选本轮最高分动作，也不是每匹配一个G条目就认定领先扩大。策略记录需明确收益基线和兑现条件；对手反制使前提失效时重新评估，已取得资源与真实进度则继续保留。

## 2. G 类：有明确证明的局部优势

### G01 同种物品合法批量交易，严格节省动作

**前提**：本来就需要在同一价格下买／卖同一物品 n 件，n>1；距离合法，现有金币、持有量、背包空位满足整批需求；提前成交没有坏处，期间没有更重要的交错动作。

**比较**：n 次各交易1件，与1次交易n件。

**证明**：相同单价下，最终金币与物品相同，批量仅用1个角色动作，节省 `n-1` 个动作。卖10块同种矿能省9个动作。省下的动作可以等待来模拟原计划，或投入更有价值工作。

**限制**：跨日涨价、分批补药等场景不符合“相同价格／无需交错”前提；不同矿种仍需不同命令。依据：任务书 §4.4、接口 §2.2 的 num。

### G02 已就位炮手的等价重新匹配，立即恢复可用火力

**前提**：两个角色当前分别可控制两座就绪炮台，交叉配对要花移动回合；角色没有任务驻留等其他约束，本轮确实需要这两座炮开火。

**比较**：按 ID／坐标交叉配对，和按当前可操控关系配对。

**证明**：后者不用移动就能同时执行两次攻击，前者两次移动没有本轮火力。重新选择配对本身不消耗游戏资源。在保持相同目标的条件下，这轮可用射击数严格多2。

**限制**：本轮开火不一定决定最终胜负，当前站位也不一定是长期最安全站位。已在原版 demo 构造盘面复现旧配对损失，见 verification。

### G03 确定尾矿的多人同时采集，得到规则规定的额外资源

**前提**：该矿本轮恰剩1次产出，两名有空位且可合法采集的工人已在旁边，其中第二人本轮没有更好的工作；不需要为此牺牲行程或关键动作。

**比较**：只让第一人采 vs 两人同时采。

**证明**：规则明确余矿不够平分时每人仍得1个，前者总得1，后者总得2，矿随后同样耗尽。相对第二人空等，严格多1矿；若有k名合法参与者，规则含义是共得k个。

**限制**：己方只有两个工人，不能把开拓者计入。接口不传矿剩余量，有对手同时采矿时难以确认；若另一人本可去采一块别的矿，就不一定有净增益。依据：任务书 L92–95；判题器尚未交叉验证。

### G04 延后一次必用升级，在安全窗口吸收伤害后再满血

**前提**：升级券已在合适角色背包里；升级前建筑在等待窗口确定不会毁；等待期不需要升级带来的射程／火力；两方案受到同样的累计伤害 D；升级操作与截止时间都可保障，且比较时点之前不会再受额外伤害。

**比较**：现在升到新上限 H，之后受伤D，剩 `H-D`；先承受D，再升级，剩H。

**证明**：同一张券、同一次动作，延后方案在比较时点严格多D血量。它利用了“升级成功恢复新等级满血”的明确机制，基地尤适合研究，因为自身无火力提升。

**限制**：当前血量可能撑不住、提前升武器能少受伤、同轮升级与致死伤害先后未知，都使前提不成立。不能执行盲目的残血贪升级。依据：任务书 L666。

### G05 单枚火箭的合法落点穷举，保证本轮模型内最大有效伤害

**前提**：已确认合法落点集合 C、射程和AOE语义，当前机器人位置及血量准确，只优化这一枚的回合末有效伤害；不考虑其他未建模交互。

对中心 c 定义：

`V(c)=sum_i min(hp_i, 20*[pos_i=c] + 10*[distance(pos_i,c)=1])`。

**算法与证明**：计算每个 `c in C` 的 V，取最大者；完整枚举有限候选集后，所得值不小于任何其他合法中心，当然包括“最近机器人”。当存在更好的溅射中心时严格改善。

地图只有1312格。若空地中心可用，任何能造成正伤害的中心都在某个机器人及其八邻格中，可先生成此并集再做合法性过滤。若空地落点不合法，C必须改为判题器接受的集合。

**限制**：这不是全局最优选靶；最大伤害可能伤到对手浪潮。加入威胁／阵营权重后最优性只针对新定义的效用。多枚导弹逐枚选最优不是联合最优证明；要联合搜索，且剪掉候选或提前超时时不能再声称全局枚举保证。空地落点见Q11。

### G06 炮弹从必然溢出目标移向另一目标，增加有效伤害

**前提**：已确认同回合命中规则；目标A已有不依赖待调整炮弹的足够致死伤害，替换这枚／束伤害不会改变其他弹道和溅射；目标B合法可命中且还有剩余血量；加特林整组扇区、火箭目标数量等仍合法，且不引入更差的威胁后果。

**比较**：继续打A，与把这部分火力转给B。

**证明**：A的回合末死亡不变，B额外承受 `min(转移伤害, B未覆盖血量)`，因此有效总伤害增加；击杀数至少不会因A复活而下降。

**限制**：待转移火力可能负责清除电磁／加特林前方拦截目标；未知结算次序下不能假设可随意移走。对手抢击杀归属或“射到后方目标途中仍被A截住”也必须排除。只对已验证独立命中的候选用这个消除规则。

### G07 无收益、确定不可能成功的动作可直接剪枝

**前提**：已知动作不可能生效，且没有有价值的探测信息，例如已确认满级建筑再用升级券、没有余量的背包继续采矿、现有金币与其他预留已使该购物无法执行。

**证明**：该动作不能产生所需状态变化；若有已知安全且有收益的替代动作，替代严格更好；若只有等待，则至少可避免无用命令、潜在异常及决策噪声。

**限制**：等待不总比失败动作在游戏分数上严格更好；有信息价值的未知动作不适用。格式错误可能停调度，普通规则执行失败通常不计异常，要分别记录。

### G08 L1 电磁炮在特定直接射击模型中弱支配 L1 加特林

**前提**：相同合法炮位、相同操作者，比较单个孤立机器人；两武器的路径均无遮挡，没有额外未描述效果；只比较当前L1、每次射击伤害与可选距离，不考虑后续升级路线。

**证明**：两者造价25、血量1000、每次有效伤害上限10、无规定冷却；电磁射程6，加特林3。距离≤3时电磁可实现相同有效伤害；距离4–6时电磁新增可攻击选项。相同近距行为可复现，故在该模型内电磁弱支配。

**限制**：L2/L3加特林可分多弹不同方向，电磁只一条弹道；未来升级价值、视线和PvP细则可能改变结论。不能据此认定“三电磁开局全局最优”。依据：任务书 §4.5.1、§4.5.4。

### G09 已验证任务 SOP 的无损复用，节省探索回合

**前提**：新任务与已验证 SOP 的接口、环境和题型约束相同；SOP重新获取当前实例数据，产出与重新探索等价的正确答案；省略的步骤只是在重复发现已知接口，无必要副作用或新信息。

**比较**：每题从头询问LLM、探索环境，与直接执行已验证流程。

**证明**：结果正确性保持不变，少k次串行工具往返就减少相应等待轮次和调用。若它使同题完整完成耗时从t+k降为t，则按刷新后的公式增加 `5*T*k/(t*(t+k))` 分，金币相同。取整规则未确认，原始公式严格增分不等于最终显示分数每次都有变化；仅省调用而未缩短完成回合时也不产生速度增分。

**限制**：不能缓存北京的旧天气来回答新的上海任务；应缓存解题过程而非无效的旧动态答案。环境、字段和任务族变化必须使SOP失效或重验。依据：任务书 §5.3 明确鼓励形成固定SOP/SKILL。

### G10 同风险、无时间副作用时，最短交互路径弱支配绕路

**前提**：同一目的、同样风险和可行性，用最短的合法交互站位路径替代更长路径，节省的回合可以安全等待；没有“故意晚到更有利”等时间效果。

**证明**：可以在提前到达后等待到原计划时间，因此至少可复现原计划；若释放的回合有正收益任务，则严格改善。多目标BFS找到的是到整个合法站位集合的最短路，不只是到预先任意选的一个格子。

**限制**：对手同时移动、机器人威胁、跨日价格和任务时间窗口会破坏“同样风险／时间效果”前提，最短静态路不等于最佳路线。

### G11 已确定完整正确的答案，在无机会成本时尽早提交

**前提**：同一任务T>0，答案已确定完整正确；现在提交合法，能使裁判确认的完成耗时为t>0；延后k>0轮仍提交同一答案；提前提交不会占掉更有价值的防守／救命动作，不损失有价值的任务期工具操作，也不触发其他更差的后续安排。

**比较**：现在完成获得 `S+5*T/t`，等待后完成获得 `S+5*T/(t+k)`。

**证明**：相减为 `5*T*k/(t*(t+k))>0`，基础分和任务金币不变。若判题器仅作通常的单调取整，计分至少不差；差额足够大时严格增分。提前完成也会让该点的30轮刷新冷却更早开始，但能否利用需结合任务库存和后续行程。

**限制**：猜测答案正确不满足前提；额外校验可能显著提升正确率，此时要比较期望收益。规则中的t是完成回合差，不能把本地提交回合或收到反馈回合直接当完成回合。依据：新版任务书§六、任务刷新规则；未用判题器实测取整。

## 3. 定量比较：有用，但不能直接升级成必胜策略

### 3.1 一石头的价值依场景而变

一块石头可建1000 HP的L1墙。若必须跑商把它卖成样例价1金币，得到的是流动资金；如果墙位没有阻挡价值，1000 HP也可能没有实战价值。要比较这堵墙能否吸收本会打向基地／炮手的伤害，以及它带来的交通阻塞。

卖掉25块石头才抵得上一座新武器的25金币，且还要运输／交易。已在基地附近的安全建墙机会可能很划算，但不能因此永远只挖石头。

### 3.2 经济按整趟工时算

例如仅作说明：10块铜卖50金币，若往返和销售需要31回合、采10回合，平均约 `50/41=1.22` 金币／工人回合；10块铁卖30金币，若物流只需11回合，平均 `30/21=1.43`。单价更低也可能周转更好。

这不是当前地图的实测路线，只说明应统计全周期。当前价格来自请求，未来价格变化再纳入库存计划。

### 3.3 任务和生存分不能忽略

请求样例的单任务基础奖励50分，数值相当于50只小机器人或5只BOSS的击杀分。现在速度奖励公式已明确，但样例未给timeoutRounds，具体题目难度和任务总量仍未知。

下面仅作公式算例：假设S=50、T=60，并且都合法完整完成；T=60不是从请求样例读取的值。

| 完成耗时t | 任务得分S+5T/t |
| --- | --- |
| 1 | 350 |
| 2 | 200 |
| 3 | 150 |
| 5 | 110 |
| 10 | 80 |
| 20 | 65 |
| 60 | 55 |

表中t=1只说明公式值，不保证任务协议实际允许1回合完成，t=T也不替代超时边界验证。从2轮拖到3轮损失50分，从10轮拖到11轮损失约2.73分，从20轮拖到21轮损失约0.71分。框架应重点消除接取后没有必要的等待和重复探索，不必为远低于一回合的本地计算加速虚构积分收益。

同样S=50时，90%部分完成得45分；若t=10合法完整完成则得80分，相差35分，其中包含解锁的30分速度奖。补齐最后字段的价值可能很高，但也要考虑成功概率和追加耗时。

标准时限T在公式中越大，同样完成耗时的速度项越大；实际长时限题可能也更难，不能只按T排序。比较任务时需要估计完整完成概率、完整完成耗时、部分得分、路程、刷新冷却和有限题目机会。

完整10天生存550分；第10天单日100分。基地已经确定保不住时，行动应比较可多活的回合／天数与可以兑现的积分，而不是机械地完成原来的投资路线。

### 3.4 火箭的平均伤害不能忽略冷却和聚团

若“发射后空3回合”意味着相隔4轮发射，L1单孤立目标的长期中心伤害仅 `20/4=5` 每轮；60轮且首轮可射时最多15次、300中心伤害。若判题器实际是相隔3轮，则是20次、400中心伤害，必须通过cooldown轨迹确定。

一枚火箭在中心及全部8邻格各有机器人且血量足够时，可造成 `20+8*10=100` 总伤害；聚团会显著改变比较。因此“火箭射程长所以一定最强”与“火箭单体慢所以没用”都不成立。

## 4. H 类：值得实验，尚不能保证收益

## 5. 明确不作确定优势的结论

- “永远最近矿”“永远铜矿”“永远只挖石头”。
- “永远最近敌人”“永远先打低血”“BOSS分高所以优先”。
- “三种炮各一座就是最优组合”“三火箭无脑最强”。
- “所有墙建满就安全”“角色死了反正保留背包所以随便死”。
- “先把金币花光再说”“召唤令一定能压制对方”。
